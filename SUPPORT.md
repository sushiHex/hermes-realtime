# Support

Hermes Realtime is experimental and maintained on a best-effort basis.

## Questions and setup help

Use GitHub Discussions for usage questions, design discussion, and requests for help. Include your operating system, Python version, Hermes Agent version, installation method, and a minimal redacted configuration.

## Bugs

Use the bug-report issue form for reproducible defects. Before filing:

1. check existing issues;
2. reproduce against current `main` or the latest release;
3. remove credentials, bearer material, launch fragments, private paths, audio, transcripts, and personal data;
4. provide the smallest safe reproduction and actual error text.

## Feature proposals

Use the feature-request issue form. Explain the public use case and why an existing Hermes or LiveKit surface does not satisfy it. Hardware-specific or private-deployment requests may be declined unless they can be expressed as a generic, reproducible capability.

## Security

Do not use Discussions or Issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md).

## No service commitment

There is no guaranteed response time, compatibility window, hosted service, or individual deployment support. Maintainers may close reports that cannot be reproduced without private hardware, private accounts, or undisclosed data.
