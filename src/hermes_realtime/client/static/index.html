    Optional local capture

    Evidence capture disclosure

    Evidence capture is optional and off until you consent.

    If you consent, Hermes Realtime stores the selected final microphone transcript text, selected final typed input text, generated assistant segment text, transport-confirmed assistant text, and content-free routing, delivery, lifecycle, and settlement metadata. These records can contain sensitive personal information. They are stored locally without encryption at rest.

    The configured retention period and bounded storage quota limit capture. Revoking consent closes capture immediately and erases the current consent epoch; older closed epochs remain until their retention deadline or an explicit full purge. Best-effort RAM cleanup cannot prove zeroization, and restart recovery may complete pending privacy work before capture becomes available.

    This evidence does not prove physical speaker identity, typed authorship, browser playout, audibility, hearing, comprehension, agreement, or truth. Slice 0 performs capture only; it does not learn from or automatically apply the stored evidence.

    Optional external search

    Public search disclosure

    Public search is optional. It is unavailable unless the host operator enables it, and it remains off for each browser session until you consent here.

    If you consent, Hermes Realtime may use a search query derived from stable partial or final speech transcript text, or final typed input text, and send that query over HTTPS to Bing Search RSS and, for outcome-shaped queries, Google News RSS. Raw microphone audio is not sent to those services by this feature.

    Search results are untrusted external data used only to support source-sensitive answers. The destinations may receive the query, network metadata such as your host's public IP address, and ordinary HTTP metadata under their own terms and privacy policies.

    Consent applies only to the active browser binding. Rebinding, projection resynchronization, stopping, inactivity expiry, or revocation closes the server gate for new lookups. Revocation cannot cancel a lookup admitted while consent was active or recall a request that was already sent.
